cstroie.github.io
=================

Source of https://cstroie.github.io/, a landing page for these browser-based retro computing projects:

- [BASIC-40](https://github.com/cstroie/basic): an 8-bit style BASIC interpreter
- [RPN-4](https://github.com/cstroie/rpn): an HP-style RPN scientific calculator
- [JSForth](https://github.com/cstroie/forth): a small, mostly standard Forth

Each project publishes its own GitHub Pages site under `/basic/`, `/rpn/` and `/forth/`.
